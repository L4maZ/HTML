Nạp dữ liệu kỳ mới

Nạp file mới sẽ thay toàn bộ dữ liệu đang hiển thị. Bản đang mở giữ dữ liệu kỳ trước cho tới khi anh nạp file mới.

C

    D

    Nhật ký nạp file

    E

    Môi trường & hướng dẫn

    Quy trình mỗi kỳ: mở File 02 → chạy macro XuatFileKey → file Key_YYYYMMDD.xlsx nằm cùng thư mục → nạp vào đây → kiểm mục C → bấm Xuất bản gửi đi. Muốn sửa một câu nhận định hay một con số: sửa thẳng trong file Key rồi nạp lại, không cần mở File 02. Toàn bộ xử lý chạy trong trình duyệt trên máy anh — không có kết nối mạng nào được tạo ra.

    Tài liệu nội bộ phục vụ quản lý rủi ro thị trường. Số liệu chưa qua soát xét độc lập.
